# FAA 复飞航图正式标注操作手册：步骤、框类型、字段对应

适用范围：`tools/shujuji_annotation` 下的练习 10 张和正式 300 张复飞航图标注网页。

核心目标：用最少人工操作，把“航图上的框”校准为可以支持 PR #28 最大 JSON 字段的证据。人工不是重新抄一份 JSON，而是确认每个框能否证明某一航图、某一复飞航段、某一字段。

一句话标准：一个可以保存为 `accepted` 的对应，必须同时说清楚“第几个航段、航段类型、哪个字段、图上哪里能看到这个值”。

---

## 1. 最终要产出什么

正式标注保存后，系统会保存三类核心内容：

1. 人工校准后的框：每个框有类型、位置、备注、人工动作。
2. 框到 PR #28 字段的对应：哪个框证明哪个航段的哪个字段。
3. 人工框生成的 `annotation_pr28_json`：格式与 CIFP/424 转换来的 `canonical_proxy_gt` 对齐，用于检查证据覆盖和字段一致性。

需要注意：

- 当前网页的评分是“人工证据覆盖/证据对齐”，不是独立模型抽取准确率。
- 424 转换来的 canonical JSON 是基准答案。
- 人工确认后，如果人工判断是对的，那么网页生成的 JSON 格式可以和 424 转换来的 JSON 严格对应。
- 如果人工把错误框、错误航段、错误字段确认了，JSON 也会跟着错，所以人工重点是确认“证据是否真的支持字段”。

## 2. 新手最少操作流程

### 2.1 进入网页

练习网页：

`http://主机IP:8787/practice/`

正式网页：

`http://主机IP:8787/formal/`

本机访问可以用：

`http://127.0.0.1:8787/formal/`

多人标注时使用局域网地址，由负责启动服务器的人告诉大家。

### 2.2 填写标注人

在右上角“标注人”输入固定编号，例如：

- `A01`
- `A02`
- `B01`
- `LXL`
- `ZhangSan`

要求：

- 每个人只用一个固定标注人编号。
- 不要多人共用同一个编号。
- 不要留空。
- 不要用 `test`、`1` 这种无法追踪的名字。

### 2.3 领取航图

正式标注必须先领取。

操作：

1. 在左栏找到未被领取的航图。
2. 点击该航图卡片中的“领取”按钮。
3. 确认左栏状态变成“我已领取”。
4. 再打开并开始校准。

状态解释：

| 状态 | 含义 | 你应该做什么 |
|---|---|---|
| 未领取 | 还没人做 | 可以点击领取 |
| 我已领取 | 当前标注人领取了 | 可以标注和保存 |
| 我已提交 | 当前标注人已经保存过 | 可以继续修改后再保存 |
| 已被某人领取 | 别人正在做 | 不要重复做 |

保存要求：

- 正式集保存时，系统会检查当前图是否由当前标注人领取。
- 没领取不能保存，避免多人重复标同一张图。

### 2.4 打开航图并调视图

点击左侧航图卡片主体打开图。

看不清时：

- 中间“航图缩放”的 `+`、`-` 可以放大缩小航图。
- 鼠标放在中间航图区域，按住 `Ctrl` 滚动鼠标滚轮，也可以缩放。
- 左栏、中间、右栏、简化操作区都可以分别缩放，互不影响。

调整框时：

- 鼠标放在框内部拖动：移动整个框。
- 鼠标放在框边线或四角附近拖动：改变框大小。
- 画新框：先在上方选择框类型，再点“框选新增”，然后在图上拖出框。

### 2.5 先粗看三个大框

打开图后先看大框，不要一上来就看 JSON。

需要看三类大框：

1. `MISSED_APPROACH_TEXT`：上方复飞文字大框。
2. `PLAN_VIEW`：平面图复飞上下文大框。
3. `MISSED_APPROACH_DETAIL_AREA`：下方复飞细节总框。

大框判断：

- 大框可以稍大，目的是覆盖完整区域。
- 大框不要求拆成很多小框。
- 大框不能明显跑偏到无关区域。
- 上方复飞文字必须完整覆盖 `MISSED APPROACH:` 后面的说明。
- 下方细节总框必须覆盖真正的复飞小表格或复飞 detail strip。

### 2.6 再看下方细节小框

小框是最重要的。小框要贴紧单个复飞相关文字或符号。

重点检查：

- 高度数字有没有框到。
- 向上爬升箭头有没有框到。
- 弯曲转弯箭头或路径有没有框到。
- fix 名称有没有框到。
- fix/navaid 图标有没有框到。
- radial、heading、track 有没有框到。
- inbound/outbound 有没有框到。
- holding 图形、holding 时间、DME/NM 距离有没有框到。

小框规则：

- 能拆开就拆开，不要一个红框框住一整格所有内容。
- 高度数字、箭头、fix 名称、radial 应尽量分别框。
- 如果同一格里有 `COE R-350 outbnd`，应该至少能分别看到 `COE`、`R-350`、`outbnd` 的证据。
- 如果预标注小框跑偏，可以拖动移动或拖边调整。
- 如果缺小框，选择合适类型后新增。

### 2.7 使用“快速确认已有候选”

如果预标注质量大体正确，可以先点“快速确认已有候选”。

适合使用：

- 小框基本在复飞细节区域内。
- 候选字段大多能从图上看出来。
- 没有大量框到普通剖面图、最低标准表或机场图。

不适合使用：

- 小框大量跑到无关位置。
- 很多重复框或明显错误框。
- 你还没看清楚这张图。

误点处理：

- 如果误点，立刻点“撤销快速确认”。
- 不要误点后直接保存。

### 2.8 处理“待确认候选”

简化操作区会显示“待确认候选”数量。

操作：

1. 点“跳到下一个待确认框”。
2. 页面选中一个框。
3. 看中间图：框的位置和类型是否对。
4. 看右侧“字段对应”：这个框要证明哪个航段、哪个字段。
5. 如果对，点“确认对应”或“确认本框并跳下一个”。
6. 如果不对，点“不属于此框”或“不确定”。

不要只看按钮就确认，必须看图上证据。

### 2.9 处理“missing 字段”

missing 字段表示 canonical JSON 中有 present 字段，但当前还没有被人工证据覆盖。

操作：

1. 在简化操作区找到“需要优先补的字段”。
2. 点某个字段的“去候选字段处理”。
3. 看它要求的航段、航段类型、字段名和值。
4. 回到航图找证据。
5. 如果图上已有合适框，点中该框，在候选目标字段里点“挂到当前框”或“挂并确认”。
6. 如果图上没有框，新增合适类型的小框，再挂字段。
7. 如果图上确实找不到，标“不确定”并备注原因。

missing 处理优先级：

1. 先处理下方复飞细节区域能看到的字段。
2. 再处理上方复飞文字能支持的字段。
3. 最后处理平面图/插图中的辅助证据。
4. 确实不可见或图上没有的，不要硬确认。

### 2.10 保存

保存前检查：

- 当前图是“我已领取”。
- 待确认候选尽量为 0。
- missing 字段中，能在图上找到的都已经处理。
- 不确定字段已备注。
- 明显错误框没有被确认。
- 没有把无关剖面高度、最低标准表、机场图误当成复飞字段。

点击右上角“保存人工校准”。

## 3. 三类大框怎么判断

### 3.1 `MISSED_APPROACH_TEXT`：上方复飞文字大框

作用：

- 覆盖航图上方 `MISSED APPROACH:` 文字说明。
- 作为复飞信息的整体文本证据。
- 可辅助支持多个字段，但正式校准仍优先用下方小框作为精细证据。

应该框住：

- `MISSED APPROACH:` 标题。
- 后面的完整句子。
- 第二行、第三行说明。
- altitude、heading、direct、fix、radial、DME、hold 等所有复飞文字。

可以接受：

- 框稍微大一点。
- 包含一点相邻空白。
- 包含标题和完整复飞句子。

不能接受：

- 只框住 `MISSED APPROACH:` 标题。
- 漏掉后半句或下一行。
- 框到主要是频率栏、跑道信息栏。
- 上方文字完全没覆盖。

处理方式：

- 框偏了：拖框内部移动。
- 框太窄或太高：拖边线调整。
- 没有这个框：选择 `MISSED_APPROACH_TEXT`，新增大框。
- 候选字段只靠这个大框：可以作为兜底，但如果下方有精细小框，优先用小框确认。

### 3.2 `PLAN_VIEW`：平面图复飞上下文大框

作用：

- 覆盖平面图中与复飞路径相关的上下文。
- 帮助确认复飞路径、fix、holding、radial、DME、备用复飞 fix 插图等。

应该框住：

- 复飞路径或 dotted missed approach path。
- 复飞 fix。
- `MISSED APCH FIX` 插图。
- holding pattern。
- 相关 navaid/radial。

可以接受：

- 覆盖整个平面图主体。
- 包含部分非复飞信息，因为它是上下文框。

不能接受：

- 没覆盖复飞路径。
- 漏掉明显的复飞 fix 或 holding 小插图。
- 只框到普通进近段而没有复飞上下文。

处理方式：

- 大框略大没有问题。
- 如果平面图复飞信息分散，可以框住主要区域；必要时保留插图内小框。
- 不要把 `PLAN_VIEW` 当作小框，不要用它直接替代所有字段证据。

### 3.3 `MISSED_APPROACH_DETAIL_AREA`：下方复飞细节总框

作用：

- 定位下方剖面图附近的复飞小表格或复飞 detail strip。
- 这个区域通常是小框精标的核心区域。

应该框住：

- 下方复飞小表格。
- 复飞步骤格。
- 高度、箭头、fix、radial、turn、holding 等所在的小条。

可以接受：

- 框比小表格稍大。
- 包含一点上下空白。

不能接受：

- 框到普通进近 profile 的大段下降轨迹。
- 框到最低标准表、机场图、跑道图。
- 漏掉真正的复飞步骤格。
- 一个复飞小表格被只框到一半。

处理方式：

- 先调整总框，再检查总框内的小框。
- 如果总框里有无关小框，需要逐个处理小框，不一定删除总框。

## 4. 小框类型与字段对应

### 4.1 总表

| 框类型 | 主要证明字段 | 应该框什么 | 常见处理 |
|---|---|---|---|
| `FIX_TEXT` | `Q1_fix_ident` | fix 名称，如 MUDRE、ZEXEL、SWOBS | 贴住文字；不要把 radial 一起框太大 |
| `FIX_SYMBOL` | `Q1_fix_ident` 辅助证据 | fix 图标、菱形、星形、三角形 | 文字和符号最好分开 |
| `NAVAID_TEXT` | `Q1_fix_ident` 或 `Q4_course_or_radial` | COE、SGD、STW、BOS 等导航台名 | 和 R-xxx 分开框 |
| `ALTITUDE_TEXT` | `Q2_altitude_constraint` | 3000、7000、8700 等高度 | 只框高度数字 |
| `PATH_SEGMENT` | `Q3_turn` 或 `Q4_course_or_radial` | 转弯弧线、路径段、弯曲箭头 | 不要框普通进近航迹 |
| `TURN_PHRASE` | `Q3_turn` | left turn、right turn、then climbing left turn | 上方文字可用，优先清晰证据 |
| `HEADING_TEXT` | `Q4_course_or_radial` | hdg 063°、heading 100° | 航图常显示整数，424 可能有小数 |
| `RADIAL_TEXT` | `Q4_course_or_radial` | R-243、R-350、R-154 | navaid、radial、in/out 尽量分开 |
| `TRACK_OR_RADIAL_TEXT` | `Q4_course_or_radial` | tr 284°、track 284°、063° | 要确认属于复飞，不是普通航迹 |
| `OUTBOUND_INBOUND_MARK` | `Q4_course_or_radial` | inbound、inbnd、outbound、outbnd | 与 navaid radial 配合确认 |
| `HOLDING_ARC` | `Q5_hold_params` | holding 弧线 | 只框 holding 相关图形 |
| `HOLDING_PATTERN` | `Q5_hold_params` | 完整等待图形 | 可辅助确认 hold 存在 |
| `HOLDING_TIME_TEXT` | `Q5_hold_params` | 1 min、One Minute Holding Pattern | 区分普通说明和 holding 参数 |
| `DME_DISTANCE_TEXT` | `Q5_hold_params` 或 fix 条件 | 20.5 DME、4 NM、5 NM | 只确认复飞/holding 相关距离 |
| `MISSED_APPROACH_ICON` | 区域上下文 | 复飞图标或关键复飞符号 | 用于定位，不一定直接对应 Q 字段 |
| `MISSED_APPROACH_STEP_BOX` | 区域上下文 | 复飞步骤格单格 | 用于辅助，不替代字段小框 |

## 5. PR #28 字段怎么对应

PR #28 最大 JSON 以航段为单位。每个航段可能包含：

- `Q_terminator`
- `Q1_fix_ident`
- `Q2_altitude_constraint`
- `Q3_turn`
- `Q4_course_or_radial`
- `Q5_hold_params`

人工确认时，必须按“航段”挂字段，而不是只看值。

### 5.1 `Q_terminator`：航段类型

含义：

- 表示这一段是什么类型的复飞航段。
- 例如 `CA`、`VI`、`CF`、`DF`、`HM`。

常见航段类型：

| 类型 | 中文理解 | 常见图上表现 |
|---|---|---|
| `CA` | 爬升到高度 | climb to 3000、向上箭头加高度 |
| `VI` | 按航向拦截/继续 | heading、course、track 后接下一段 |
| `CF` | 飞向指定点 | direct/fly to fix，fix 名称明显 |
| `DF` | direct to fix | direct FIX |
| `HM` | 等待航段 | hold、holding pattern、racetrack |

人工要做什么：

- 通常不需要为 `Q_terminator` 单独画框。
- 它多来自 424 编码，页面可自动带出。
- 你只需要确认这个航段的其他字段证据是否符合这个航段类型。

何时需要注意：

- 如果候选显示 `HM`，但图上完全没有 hold 或 holding pattern，要标不确定。
- 如果候选显示 `CF`，但挂到的是高度数字而不是 fix，要拒绝。
- 如果航段类型和图上证据明显冲突，不要强行确认。

### 5.2 `Q1_fix_ident`：定位点 / 导航台

含义：

- 这个航段要飞向、使用或等待的 fix/navaid。

常见值：

- `MUDRE`
- `ZEXEL`
- `SWOBS`
- `TELLE`
- `EVVIS`
- `COE`
- `BOS`
- `SGD`
- `AHN`

应使用的框类型：

- `FIX_TEXT`
- `NAVAID_TEXT`
- `FIX_SYMBOL` 作为辅助

确认标准：

- 框内能看见目标 fix/navaid 名称。
- 名称属于复飞指令或复飞小表格。
- 航段编号正确。
- 如果同一个名称出现在多个位置，优先选择复飞小表格或复飞文字中最直接的位置。

示例：

- 字段显示：`航段 2 · CF · Q1_fix_ident = MUDRE`
- 图上框：`MUDRE INT`
- 操作：如果这个 `MUDRE` 属于复飞步骤，点“确认对应”。

不能确认：

- 当前框是 `3000`，却要对应 `Q1_fix_ident = MUDRE`。
- 当前框是普通进近 fix，不是复飞航段目标。
- 框只框到 `INT`，没有框到 fix 名称。

### 5.3 `Q2_altitude_constraint`：高度限制

含义：

- 这个航段要求爬升到、保持不低于、继续爬升到某高度。

常见值：

- 不低于 `3000 ft`
- `7000 ft`
- `8700 ft`
- `11000 ft`
- `6500 ft`
- `4000 ft`

应使用的框类型：

- `ALTITUDE_TEXT`
- 上方 `MISSED_APPROACH_TEXT` 可作为兜底证据。

确认标准：

- 框内清楚看到高度数字。
- 该高度属于复飞，不是最低标准、机场标高、TDZE、跑道长度。
- 如果 424 写 `AT_OR_ABOVE 3000 ft`，航图上看到 `3000`，可以确认。
- 如果航图写 `Climb to 3000`，可以对应高度限制。

示例：

- 字段显示：`航段 2 · Q2_altitude_constraint = 不低于 3000 ft`
- 图上框：`3000`
- 操作：确认高度属于复飞步骤后，点“确认对应”。

不能确认：

- 框到最低标准表里的 `3000`。
- 框到机场图或跑道信息中的数字。
- 高度属于进近下降剖面，而不是复飞指令。

特殊情况：

- 同一张图可能有多个高度，例如 `2900`、`6000`、`6500`。必须按航段顺序分别对应。
- 小表格中每个高度通常对应不同步骤，不要把一个高度确认到多个不相关航段。

### 5.4 `Q3_turn`：转弯方向 / 转弯证据

含义：

- 这一航段是否 left turn、right turn，或者通过路径图形表现转弯。

应使用的框类型：

- `PATH_SEGMENT`
- `TURN_PHRASE`
- `HOLDING_ARC` 有时可辅助

确认标准：

- 图上能看到转弯弧线、弯曲箭头或文字说明。
- 方向和字段一致。
- 如果字段是 `RIGHT`，图上应能支持右转。
- 如果字段是 `LEFT`，图上应能支持左转。

示例：

- 字段显示：`航段 2 · VI · Q3_turn = RIGHT`
- 图上框：复飞小表格里的右转弧线
- 操作：确认弧线方向是右转后确认。

不能确认：

- 框到普通进近路径，不是复飞转弯。
- 框到无箭头的无关线段。
- 方向不清楚时不要硬确认。

特殊情况：

- 有些图只在上方文字写 `climbing left turn`，下方小表格也有弧线。优先确认下方弧线；如果下方没有清晰证据，可以用上方文字大框或新增 `TURN_PHRASE`。

### 5.5 `Q4_course_or_radial`：航向 / 径向 / 航迹

含义：

- 这一航段的 heading、track、course、radial 或 navaid radial 信息。

常见形式：

- `hdg 063°`
- `heading 100°`
- `tr 284°`
- `STW R-243`
- `COE R-350 outbound`
- `BOS R-154`

应使用的框类型：

- `HEADING_TEXT`
- `TRACK_OR_RADIAL_TEXT`
- `RADIAL_TEXT`
- `NAVAID_TEXT`
- `OUTBOUND_INBOUND_MARK`

确认标准：

- 框内能看到航向、径向或航迹文字。
- 如果字段包含 navaid + radial + direction，要尽量分别确认这些组成部分。
- 如果 424 是 `63.3°`，航图上显示 `063°`，通常可以认为是同一航向的航图取整显示；不要在图上强行找 `63.3°`。
- 如果 424 是 `294.4°`，航图显示 `294°` 或 `294`，通常按航图整数显示确认。

示例 1：

- 字段显示：`Q4_course_or_radial = course_deg 63.3`
- 图上框：`hdg 063°`
- 操作：如果这是复飞第一段 heading，确认。

示例 2：

- 字段显示：`Q4_course_or_radial = STW R-243 inbound`
- 图上框：`STW`、`R-243`、`inbound`
- 操作：分别用 `NAVAID_TEXT`、`RADIAL_TEXT`、`OUTBOUND_INBOUND_MARK` 支持；如果系统候选挂到了一个包含完整信息的框，也可确认，但优先细分。

不能确认：

- 把普通 final approach course 误认为复飞航向。
- 框到 `APP CRS`、跑道航向、MSA 角度，但它们不属于复飞字段。
- `R-243` 挂到 `Q1_fix_ident`。
- `MUDRE` 挂到 `Q4_course_or_radial`，除非它作为完整复飞文字大框证据的一部分且确实支持字段。

### 5.6 `Q5_hold_params`：等待参数

含义：

- holding 的参数，包括 holding fix、inbound course、leg time、leg distance、turn direction 等。

应使用的框类型：

- `HOLDING_PATTERN`
- `HOLDING_ARC`
- `HOLDING_TIME_TEXT`
- `DME_DISTANCE_TEXT`
- `FIX_TEXT`
- `TRACK_OR_RADIAL_TEXT`

确认标准：

- 图上能看到 hold、holding pattern、等待弧线或等待文字。
- holding fix 要和 `Q1_fix_ident` 或 hold 参数中的 fix 一致。
- inbound course、时间、距离、turn direction 要能从图上或文字中看到。

示例：

- 字段显示：`Q5_hold_params = inbound_course_deg 243.1, leg_time_min 1, turn RIGHT`
- 图上框：holding racetrack、`243°`、`One Minute Holding Pattern`
- 操作：分别确认对应证据。

不能确认：

- 只看到普通转弯弧线，没有 hold 或 racetrack，就确认 holding。
- 把 MSA 圆里的图形误认为 holding。
- 把 FAF 到 MAP 距离当成 holding 距离。

## 6. 候选字段怎么挂到当前框

### 6.1 图上已有框，字段还 missing

操作：

1. 在简化操作区点“去候选字段处理”。
2. 记住它要求的航段、航段类型、字段和值。
3. 在中间图上点击能证明该值的框。
4. 看右侧“候选目标字段”。
5. 找到同一个航段、同一个字段。
6. 点“挂到当前框”。
7. 如果很确定，再点“已挂，直接确认”或在“字段对应”点“确认对应”。

检查标准：

- 当前框里的值必须和候选字段的“应看到”一致。
- 航段编号必须一致。
- 字段名必须一致。
- 类型最好匹配，例如高度用 `ALTITUDE_TEXT`，fix 名称用 `FIX_TEXT`。

### 6.2 图上没有框，字段还 missing

操作：

1. 看 missing 字段要求什么值。
2. 在航图中找到对应文字或符号。
3. 在中间上方下拉框选择框类型。
4. 点“框选新增”。
5. 贴紧目标文字或符号画框。
6. 如果框画得不准，用拖动移动或拖边调整大小。
7. 到“候选目标字段”把该字段挂到当前框。
8. 确认对应。

例子：

- 缺 `Q2_altitude_constraint = 4000 ft`：选择 `ALTITUDE_TEXT`，框住 `4000`。
- 缺 `Q1_fix_ident = EVVIS`：选择 `FIX_TEXT`，框住 `EVVIS`。
- 缺 `Q4_course_or_radial = R-350 outbound`：分别选择 `RADIAL_TEXT` 框 `R-350`，选择 `OUTBOUND_INBOUND_MARK` 框 `outbnd`，必要时选择 `NAVAID_TEXT` 框 `COE`。
- 缺 `Q5_hold_params`：选择 `HOLDING_PATTERN` 或 `HOLDING_ARC` 框等待图形，必要时补 `HOLDING_TIME_TEXT` 或 `DME_DISTANCE_TEXT`。

### 6.3 已挂错了怎么办

如果某个字段已经挂到当前框，但发现不对：

1. 在候选字段卡片上点“取消挂接”。
2. 或在“字段对应”里点“不属于此框”。
3. 再选择正确框重新挂接。
4. 如果没有正确框，新增框后再挂。

常见错挂：

- `3000` 被挂成 `Q1_fix_ident`。
- `MUDRE` 被挂成高度字段。
- `R-243` 被挂成 fix 字段。
- 上方大框被用来确认所有字段，但下方有更精确小框没有使用。

### 6.4 一个框能不能对应多个字段

可以，但要谨慎。

可以：

- 一个上方复飞文字大框可以作为多个字段的兜底证据。
- 一个较完整的小格框如果清楚包含 `COE R-350 outbnd`，可以辅助多个 `Q4` 子信息。

更推荐：

- 高度、箭头、fix、radial、inbound/outbound 分别小框。
- 小框越精确，后续 OCR/模型评估越清楚。

不要：

- 用一个过大的框覆盖半张图，然后确认所有字段。
- 用一个无关框挂多个字段。

## 7. 各种情况怎么处理

### 7.1 框位置不准

处理：

- 框整体偏移：鼠标放框内部拖动。
- 框太大或太小：鼠标放边线或角上拖动。
- 调整后，右侧坐标会自动更新。
- 人工动作会标记为“已调整位置/大小”。

判断：

- 调整到能清楚看到目标值即可。
- 小框尽量贴住单个目标。
- 不需要像素级完美，但不能框到错误内容。

### 7.2 多框重复

处理：

- 保留最准确、最清楚、最贴近的框。
- 正确框确认对应。
- 重复但无害的框可以不确认。
- 明显无关重复框可删除或标“不属于此框”。

不要：

- 把同一个值重复确认到多个不相关字段。
- 为了减少 missing，把重复框随便挂字段。

### 7.3 少框

处理：

- 先确认是否真的缺证。
- 如果字段 present 且图上能看到，新增对应类型小框。
- 新增后挂接候选字段并确认。

优先补：

1. 高度。
2. fix/navaid 名称。
3. radial/heading/track。
4. turn/arc/path。
5. holding 参数。
6. DME/NM 距离。

### 7.4 额外框或无关框

处理：

- 明显框到无关内容：删除或标“不属于此框”。
- 可能有用但不确定：标“不确定”，备注原因。
- 不要让无关框进入 accepted mapping。

无关内容常见来源：

- 普通进近 profile。
- 最低标准表。
- 机场图。
- 频率栏。
- MSA 圆。
- 跑道长度、TDZE、机场标高。

### 7.5 航图上找不到 424 的精确小数

常见情况：

- 424 显示 `63.3°`，航图显示 `063°`。
- 424 显示 `294.4°`，航图显示 `294°`。
- 424 radial 有小数，航图显示整数。

处理：

- 航图通常显示取整值。
- 如果方向、上下文、航段都一致，可以按航图整数确认。
- 不要因为找不到小数点就认为 missing。
- 如果角度差异很大，标不确定。

### 7.6 本图本来就没有的字段

如果 PR #28 JSON 中某字段状态是：

- `not_applicable`
- `not_observable`
- `unknown`

通常不需要人工画框。

页面表现：

- 这些字段不会作为需要优先补的 present missing。
- 它们可能在详细 JSON 里出现，但不是人工标注重点。

人工不要做：

- 不要为了填满最大集合而给不存在字段乱画框。
- 不要把无关内容确认到 not_applicable 字段。

### 7.7 图上文字不清楚

处理：

- 放大中间航图。
- 看上方复飞文字、下方小表格、平面图是否有另一个更清楚位置。
- 如果仍然无法判断，标“不确定”。
- 备注写清原因，例如“文字模糊，疑似 EVVIS”。

### 7.8 航段顺序不确定

处理：

- 先读上方 `MISSED APPROACH:` 文字。
- 按动作顺序理解复飞：先 climb，再 turn/direct，再 intercept/fly to fix，再 hold。
- 对照下方小表格从左到右或按箭头顺序。
- 对照候选字段的航段类型。

不要：

- 只因为值一样就挂到任意航段。
- 把 hold 航段字段挂到 climb 航段。

## 8. 保存前逐项检查清单

保存前按下面顺序看一遍：

1. 标注人已填写。
2. 当前图已由自己领取。
3. 上方复飞文字大框覆盖完整。
4. 平面图上下文大框没有明显漏掉复飞区域。
5. 下方复飞细节总框覆盖正确小表格。
6. 高度小框没有漏掉主要复飞高度。
7. fix/navaid 名称小框没有漏掉主要目标。
8. radial/heading/track 小框没有明显错挂。
9. turn/arc/path 小框没有框到普通进近路径。
10. holding 相关字段只在确实有 hold 时确认。
11. 简化操作区待确认候选尽量为 0。
12. missing 中能在图上找到的字段已经补证。
13. 不确定内容已有备注。
14. 明显错误框没有 accepted。
15. 保存。

## 9. 快速例子

### 9.1 `Climb to 3000 on heading 063° and STW R-243 to MUDRE ... hold`

可能对应：

- `3000` -> `ALTITUDE_TEXT` -> `Q2_altitude_constraint`
- `hdg 063°` -> `HEADING_TEXT` -> `Q4_course_or_radial`
- `STW` -> `NAVAID_TEXT` -> `Q4_course_or_radial`
- `R-243` -> `RADIAL_TEXT` -> `Q4_course_or_radial`
- `MUDRE` -> `FIX_TEXT` -> `Q1_fix_ident`
- holding 图形或文字 -> `HOLDING_PATTERN` / `HOLDING_ARC` -> `Q5_hold_params`

### 9.2 `Climb to 7000 direct ZEXEL and hold`

可能对应：

- `7000` -> `ALTITUDE_TEXT` -> `Q2_altitude_constraint`
- `ZEXEL` -> `FIX_TEXT` -> `Q1_fix_ident`
- fix 符号 -> `FIX_SYMBOL` -> 辅助支持 `Q1_fix_ident`
- holding 图形 -> `HOLDING_PATTERN` -> `Q5_hold_params`

### 9.3 `Climb to 2900 then climbing left turn to 6000 on COE R-350 outbound then ... 6500 on COE R-350 inbound`

可能对应：

- `2900` -> 第一段高度。
- 第一段向上箭头 -> 第一段 climb 证据。
- `6000` -> 下一段高度。
- 左转弧线 -> `Q3_turn = LEFT`。
- `COE` -> navaid。
- `R-350` -> radial。
- `outbnd` -> outbound。
- `6500` -> 后续高度。
- `inbnd` -> inbound。
- 末尾 `COE` 或符号 -> 终点/holding fix 证据。

重点：

- 这些值不能全挂到同一个航段。
- 要按航段顺序分开确认。

## 10. 最常见错误

1. 把普通进近剖面高度当成复飞高度。
2. 把上方大框当成所有字段的唯一证据，漏掉下方小框。
3. 高度、fix、radial 混在一个小框里，没有拆分。
4. 同一个符号被重复确认到多个不相关字段。
5. 看到 424 有 `63.3°`，航图没有小数，就误以为找不到。
6. 没领取就标注，导致保存失败。
7. 字段 missing 还没处理就保存。
8. 不确定时硬点确认。
9. 误把 MSA 圆、跑道图、最低标准表内容当成复飞字段。
10. 航段编号没看清，值对了但挂到错误航段。

## 11. 标注员一句话操作口诀

先领取，后开图；先大框，后小框；先看图，再确认；先按航段，再看字段；能小框不用大框；不确定就备注；保存前看 missing。
