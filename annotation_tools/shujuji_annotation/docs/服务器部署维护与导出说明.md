# 服务器部署维护与导出说明

本文记录公网标注平台的运行、保存、导出和备份约定。文档中不写真实密码、真实访问 token 或云账号信息。

## 运行入口

正式标注入口格式：

```text
http://<server-ip-or-domain>/formal/?token=<annotation-token>
```

练习标注入口格式：

```text
http://<server-ip-or-domain>/practice/?token=<annotation-token>
```

管理员导出入口格式：

```text
http://<server-ip-or-domain>/admin/?admin_token=<admin-export-token>
```

普通标注链接只发给标注人员。管理员导出链接只给项目负责人使用。

## 服务器端保存位置

运行时数据应写入持久化目录，例如：

```text
/data/shujuji_annotation
```

正式集标注结果位于：

```text
/data/shujuji_annotation/datasets/formal300/annotations/
```

关键子目录：

- `claims.json`：领取记录与提交状态。
- `drafts/`：暂存结果。
- `by_annotator/`：每位标注人的当前正式提交结果。
- `submissions/`：每张图每次正式提交的历史快照。

平台 API 不应向浏览器返回服务器绝对路径。

## 管理员导出

配置 `SHUJUJI_ADMIN_TOKEN` 后，管理员可以通过 `/admin/` 页面生成当前标注结果导出。导出文件会保存在：

```text
/data/shujuji_annotation/exports/
```

导出 JSON 使用 schema：

```text
shujuji_annotation_export_v1
```

导出内容包括：

- 练习集暂存、正式结果和提交快照。
- 正式集领取记录、暂存、正式结果和提交快照。
- 每类结果的数量统计。

## 自动导出

可将 `scripts/server_export_web_results.sh` 安装到服务器，例如：

```bash
sudo install -m 700 tools/shujuji_annotation/scripts/server_export_web_results.sh /usr/local/bin/export-shujuji-web-results.sh
```

推荐 cron：

```cron
25 * * * * root /usr/local/bin/export-shujuji-web-results.sh >/var/log/shujuji-web-result-export.log 2>&1
```

这会每小时调用本机平台接口生成一次导出 JSON，并保留最近约 30 天的导出文件。

## 自动备份

可将 `scripts/server_backup_annotations.sh` 安装到服务器，例如：

```bash
sudo install -m 700 tools/shujuji_annotation/scripts/server_backup_annotations.sh /usr/local/bin/backup-shujuji-annotations.sh
```

推荐 cron：

```cron
15 * * * * root /usr/local/bin/backup-shujuji-annotations.sh hourly >/var/log/shujuji-annotation-backup-hourly.log 2>&1
30 3 * * * root /usr/local/bin/backup-shujuji-annotations.sh daily >/var/log/shujuji-annotation-backup-daily.log 2>&1
40 3 * * 0 root /usr/local/bin/backup-shujuji-annotations.sh weekly >/var/log/shujuji-annotation-backup-weekly.log 2>&1
```

默认备份位置：

```text
/data/shujuji_annotation_backups/
```

默认保留策略：

- `hourly`：约 3 天。
- `daily`：约 30 天。
- `weekly`：约 90 天。
- `manual`：约 180 天。

每个备份包旁边都有 manifest 文件，记录备份时间、结果数量和 sha256 校验值。

## 维护注意

- 服务器到期前续费，不要释放实例。
- 不要删除 `/data/shujuji_annotation` 和 `/data/shujuji_annotation_backups`。
- 标注链接中的 token 等同访问钥匙，不要发到公开群。
- 建议在云控制台开启实例快照或云硬盘快照。
- 标注进行中可定期从管理员页下载导出 JSON 到本地留存。
