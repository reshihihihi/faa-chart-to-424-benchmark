# 公网部署说明

目标是把现有标注平台从“局域网访问”扩展为“公网网页访问”，同时不改变原实验目的：标注人仍然通过网页领取航图、检查预标注框、暂存、正式提交，服务端仍然保存完整 JSON。

## 推荐部署方式

推荐使用 Render、Railway、Fly.io、VPS、学校服务器等支持 Node.js 服务端和持久化磁盘的平台。不要使用纯静态托管，因为平台需要服务端写入暂存和正式提交结果。

## 必须设置的环境变量

```text
PORT=8787
PUBLIC_BASE_URL=https://你的公网域名
SHUJUJI_ACCESS_TOKEN=一段随机口令
SHUJUJI_DATA_ROOT=/data/shujuji_annotation
```

- `SHUJUJI_ACCESS_TOKEN` 用于保护 API 和图片接口，公网部署必须设置。
- `SHUJUJI_DATA_ROOT` 必须指向持久化磁盘，否则重新部署可能丢失人工标注结果。
- `PUBLIC_BASE_URL` 只用于服务端日志提示，不参与权限判断。

## 发给标注人的链接

练习集：

```text
https://你的公网域名/practice/?token=一段随机口令
```

正式集：

```text
https://你的公网域名/formal/?token=一段随机口令
```

前端会在第一次打开时把 token 存到浏览器 sessionStorage，并从地址栏移除 token。之后领取、图片加载、暂存、正式提交都会自动带上 token。

## 保存位置

如果设置了 `SHUJUJI_DATA_ROOT=/data/shujuji_annotation`，运行时文件会写入：

```text
/data/shujuji_annotation/datasets/formal300/annotations/
/data/shujuji_annotation/datasets/practice10/annotations/
```

项目仓库中的 `datasets/*/images`、`datasets/*/prelabels`、`datasets/*/targets` 仍作为只读实验素材使用。

## 安全检查

部署前后需要检查：

- `/healthz` 不返回服务器绝对路径。
- 无 token 访问 `/api/charts?dataset=formal300` 应返回 `401`。
- 带 token 访问 `/api/charts?dataset=formal300&token=...` 应返回 300 张航图。
- 浏览器页面保存/暂存成功提示中不能出现服务器路径。
- 不提交 `.env`、运行日志、`runtime_data/` 或真实人工标注结果。
