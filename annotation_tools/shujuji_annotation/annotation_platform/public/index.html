普通参与者操作说明

          

          
        

        

          

            
主流程

            
    
              
  1. 正式标注会自动领取下一张可做航图；练习集可在左侧选择航图。
    2. 
              
  2. 如果当前正式航图超出能力范围，点击“提交专家复核”。
    3. 
              
  3. 按右侧“当前字段任务”逐个字段判断。
    4. 
              
  4. 先核对当前字段的证据篮子：系统会自动填入候选框，可以加入、移除、微调或画新框。
    5. 
              
  5. 选择来源类型并确认：直接图面证据、多证据综合、规则/默认补全、缺少足够编码信息或不确定。
    6. 
              
  6. 字段全部处理后点击“提交”。
    7. 
            

          

          

            
来源类型

            
“多证据综合”和“规则/默认补全”都必须先选证据框。前者表示多个框共同构成一个可见事实；后者表示这些框只是前提，还需要航图省略、程序规则或默认语义补全。

          

          

            
专家复核

            
领取后发现航图超出能力范围，使用“提交专家复核”。系统会先暂存当前已做的证据篮子，再把该图移出普通标注队列。
