## 2. 实验组2研究的问题

实验组1回答的是：每个方法生成的程序字段是否正确。

实验组2进一步回答的是：这些正确或错误和人工标注的证据来源有什么关系。换句话说，实验组2不是重新跑模型，而是把人工标注的“字段证据来源”与实验组1的字段级评分连接起来，分析不同方法在不同证据条件下的表现。

实验组2重点看三类问题：

1. 当字段答案应该填写时，不同方法在不同证据来源下的正确率如何。
2. 当字段不适用时，不同方法是否会乱填、漏给状态、给未知状态，或者正确保持不适用。
3. 人工证据标注和实验组1字段评分是否能可靠对齐，是否存在跨航段借证据、应填写字段没有证据、不适用字段却挂了证据等审计问题。

## 5. 实验组2具体怎么做

实验组2的处理流程如下。

第一步，读取后台导出的人工标注。每张图的标注中包含字段级人工判断、证据区域、证据来源、是否能支持编码等信息。

第二步，读取实验组1的字段级评分。实验组1评分告诉我们每个方法在每个字段上是否正确。

第三步，把同一张图、同一个航段、同一个字段的人工证据标注和实验组1评分行连接起来。连接后的每一行同时包含：

| 内容 | 含义 |
|---|---|
| 方法编号 | 例如 A1、C2、D1 |
| 航图编号 | 例如某机场某程序 |
| 字段名称 | 例如航段类型、定位点、高度、转弯、航向或径向、等待参数 |
| 目标状态 | 该字段应该填写、应该不适用，或其他状态 |
| 方法预测 | 方法给出的字段状态和值 |
| 是否正确 | 实验组1字段评分结果 |
| 证据来源 | 人工标注认为该字段依据哪里得到 |
| 证据类别 | 文本直接证据、平面图直接证据、规则或默认补全等 |

第四步，处理直接飞向字段的证据补全。部分直接飞向相关字段在人工标注中以区域映射形式存在，但没有落成字段级证据行。本次只允许在同一张图、同一个航段内补充这类证据，不允许跨航段借证据。

## 8. 按证据来源分析

实验组2最重要的价值是把正确率拆到证据来源上看。不同证据来源的难度不同，方法表现也不同。

### 8.1 文本、图面、规则补全三类证据的总体差异

下表列出主要证据类别下的正确率。每个类别的分母对所有方法相同。

几个现象很清楚。

第一，D1 在“规则或默认补全”上优势最大，正确率达到 81.51%。这说明 D1 不只是抄显式文字，在需要根据程序规则、默认值或编码约定补齐字段时也能稳定输出。

第二，D1 在“下方细节区或图中文字证据”上也最高，正确率为 77.94%。这类证据通常不是主程序文字句子，而是图上或下方细节区的局部信息。D1 在这类证据上的优势说明它对版面信息的利用更强。

第三，“平面图直接证据”对所有方法都很难。即使 D1 最高，也只有 14.55%；C2 为 9.70%；其他方法多数接近 0。这说明仅凭平面图直接提取编码字段仍是主要薄弱点。

第四，C4 和 C2 在“文本直接证据”上很强，分别为 80.28% 和 77.46%，高于 D1 的 40.85%。这说明 D1 的整体优势不是来自所有证据类型都绝对最高，而是来自规则补全、图中文字和总体字段覆盖能力。文本直接证据这块，C4 与 C2 有明显竞争力。

第五，“图上证据不足”这一类中，只有 D1 有较高正确率，达到 48.34%。这不能简单解释为 D1 真正看到了证据，因为人工标注认为该图上证据不足；更谨慎的解释是：D1 在这些字段上可能依靠程序结构、默认规则或其他上下文给出了与目标一致的答案。

## 11. 对主要方法的解释

### 11.1 D1

D1 是当前最强方法。它在 200 张上全部有评分，正类字段正确率为 72.41%，不适用字段正确保持比例为 86.36%。

D1 的优势集中在三点：

1. 对规则或默认补全字段非常强，正确率 81.51%。
2. 对航段类型、航向或径向、高度等编码核心字段非常强。
3. 对不适用字段的边界控制最好，乱填最少。

D1 的主要弱点是等待参数和转弯字段。等待参数只有 12.63%，转弯字段为 34.62%。这说明即使 D1 整体领先，复杂等待程序的细节仍然没有充分解决。

### 11.2 C2

C2 是第二名，正类字段正确率为 38.47%。它在高度和转弯字段上表现突出，转弯字段达到 96.15%，高度达到 61.78%。在可见直接证据和规则补全中，C2 都是非 D1 方法里最稳的。

但 C2 的不适用字段边界非常差，乱填比例达到 91.77%。这意味着 C2 的策略更像是“尽量填写”，在应该填写的字段上能拿到较多正确，但在不该填写的位置会产生大量过度填写错误。因此，C2 不能简单被描述成第二可靠的方法；更准确地说，它是正类字段上第二强，但负类边界很弱。

### 11.3 C3 和 C4

C3 与 C4 的总体正类正确率接近，分别为 27.08% 和 26.95%。C4 在文本直接证据和定位点或导航台字段上较强；C3 在定位点或导航台上也有一定优势。

C3 有 4 张结构校验未通过或无评分，已按方法失败计入。C4 没有这类缺失。两者的不适用字段正确保持比例都明显好于 C2，但正类字段整体远低于 D1。

### 11.4 B 类方法

B1_prime 比 B1 有明显提升，正类字段正确率从 17.35% 提高到 24.98%。B1_prime_link 在文本直接证据上有一定表现，但总体只有 11.74%，主要受规则补全、航段类型、航向或径向、高度和方法失败影响。

B 类方法的共同特征是：某些局部字段可以做对，例如转弯或定位点，但高度、等待、航向或径向等关键字段较弱，导致整体表现不够稳定。

### 11.5 A 类方法

A1 和 A2 整体最弱。A1 正类字段正确率为 15.42%，A2 为 9.68%。A1 在局部字段上略好于 A2，但两者在规则补全、平面图直接证据、等待参数和航向或径向上都很弱。

## 12. 最重要的实验结论

可以写入正式结果的结论如下。

第一，实验组2完成了正式三百张人工证据标注，并在实验组1的 200 张正式评分样本上完成了成对比较。

第二，当前结果显示 D1 在正类字段正确率和不适用字段边界上都显著领先。D1 正类字段正确率为 72.41%，第二名 C2 为 38.47%。

第三，D1 的优势主要来自规则或默认补全、图中文字或细节区证据、航段类型、航向或径向、高度字段，以及对不适用字段的边界控制。

第四，C2 是正类字段上的第二强方法，但它严重过度填写不适用字段。因此 C2 的结果必须和负类边界一起解释，不能只看正类字段正确率。

第五，平面图直接证据和等待参数仍是所有方法的薄弱点。即使 D1 领先，这两个部分也没有达到稳定可用的程度。

第六，本次连接审计没有发现阻塞性问题。跨航段或同字段回退取证据为 0，应填写但无同航段证据为 0，不适用字段挂证据为 0。

## 13. 不能过度解释的地方

本实验不能直接说明模型完整生成一份程序的成功率。这里统计的是字段级结果，不是整张图或整条程序是否完全正确。

本实验也不能把三百张标注全部作为严格方法比较。严格比较只使用实验组1有评分样本的 200 张。剩余 100 张可以作为标注覆盖和后续补充分析，但不能直接混入主比较。

对于 B1_prime_link 的 15 张和 C3 的 4 张无评分情况，本次按方法失败计入。这是保守处理，但也意味着它们的总分包含结构校验失败的惩罚。

对于“图上证据不足”字段，方法答对不代表模型一定找到了人工可验证证据，只能说明输出和目标一致。这里应谨慎表述。
