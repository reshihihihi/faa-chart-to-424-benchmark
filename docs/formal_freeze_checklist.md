# Formal Freeze Checklist

This checklist gates formal evaluation. Do not run the formal evaluation split
until every applicable item is complete.

## Schema And Targets

- [ ] Canonical schema imported from fixed upstream commit.
- [ ] Schema sha256 recorded in `configs/frozen_experiment_manifest.json`.
- [ ] Target generation/export source commit recorded.
- [ ] Target files have sha256 checksums.
- [ ] Scorer and validator versions are fixed.
- [ ] Composite scoring policy is documented.

## Data And Splits

- [ ] `benchmark_exports/derived/v2/MANIFEST.json` exists.
- [ ] `sample_manifest.jsonl` exists and covers all formal samples.
- [ ] `splits.json` exists.
- [ ] Development, evaluation, probe, and pilot/external samples are disjoint.
- [ ] Evaluation split is locked.
- [ ] Family-disjoint or other split constraints are checked and reported.
- [ ] Pilot-10 samples are not silently mixed into formal evaluation.

## Methods

- [ ] Method registry exists.
- [ ] Each method has allowed inputs.
- [ ] Each method has forbidden inputs.
- [ ] Oracle and deployable methods are separated.
- [ ] C3 questionnaire path and parser path are fixed.
- [ ] A1 rules runner is frozen before A1 enters a formal table.

## Prompts And Models

- [ ] Prompt files are versioned.
- [ ] Prompt sha256 values match the files.
- [ ] Model provider, model name, version/date, temperature, max tokens, image
  settings, and retry policy are recorded.
- [ ] No API tokens or credentials are committed.
- [ ] Prompt tuning did not use evaluation split failures.

## Parser And Reruns

- [ ] Parser repair policy is frozen.
- [ ] Semantic repair is disallowed unless the method is explicitly registered as
  an oracle/diagnostic path.
- [ ] Mechanical JSON normalization is defined before running.
- [ ] Rerun policy is frozen.
- [ ] New prompt/model/parser versions create new run ids.

## No-Leakage And Audit

- [ ] Input manifest builder exists.
- [ ] No-leakage validator exists.
- [ ] Formal runners cannot read target directories.
- [ ] Counterfactual labels and error fields are stripped from method inputs.
- [ ] Failed samples, invalid JSON, parse errors, and retry records are preserved.

## Reporting

- [ ] Bootstrap or paired-delta policy is frozen.
- [ ] Main tables are generated by scripts.
- [ ] Point estimates and confidence intervals are reported where required.
- [ ] Limitations and responsible-use statements are drafted.
- [ ] Dataset Card, Evaluation Card, Croissant metadata, and artifact manifest are
  planned or complete.
