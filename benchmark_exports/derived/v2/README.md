# Paper-v2 Benchmark Export

This directory is the intended read-only data entry point for formal paper-v2
experiments.

Required files before formal evaluation:

- `MANIFEST.json`
- `sample_manifest.jsonl`
- `splits.json`
- `field_targets.jsonl`
- `checksums.sha256`

Optional or task-specific files:

- `roi_manifest.jsonl`
- `gold_ma_text.jsonl`
- `evidence_provenance.jsonl`
- `challenge_tags.jsonl`
- `gold_observable_evidence.jsonl`
- `verification_counterfactuals.jsonl`
- `source_views/`

This directory is currently scaffold-only.
